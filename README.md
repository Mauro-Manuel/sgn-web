# SGN — Frontend (primeira etapa)

Implementação inicial da página de Login, baseada no mockup aprovado.

## Executar

```bash
npm install
npm run dev
```

Abrir o endereço exibido no terminal (normalmente http://localhost:5173).

## Validar compilação

```bash
npm run build
```

## Estado

- Página de Login responsiva: pronta.
- Mostrar/ocultar palavra-passe: pronto.
- Validação HTML de campos obrigatórios: pronta.
- Autenticação real: **não implementada**. Será integrada posteriormente com o Spring Security e sessões.
- Identidade gráfica: símbolo do galo e bandeira decorativa são provisórios; substituir por arte institucional autorizada.
- "Manter sessão iniciada": apenas elemento visual, ainda sem efeito até definição da política de sessão.

## Próximo passo

Confirmar visualmente a página nos browsers desktop e mobile; em seguida, organizar rotas e integrar login.
